# JY's ASMR 🌙

一个 ASMR 视频收藏站，基于 GitHub Pages 构建。

## 功能

- 🔍 **搜索** — 按视频名称、关键词多词搜索
- 🏷️ **标签云** — 热门标签一键筛选
- ⚡ **充电专属** — 一键筛选充电专属视频
- ⭐ **收藏夹** — 收藏喜欢的视频，支持仅显示收藏
- 🎲 **随机抽取** — 睡前随机抽一个视频
- 📅 **排序** — 按时间、名称排序
- 📺 **站内播放** — B站 iframe 站内播放
- 📊 **分页** — 自动分页浏览
- ⚙️ **管理后台** — 添加、批量导入、管理、导出视频数据

## 管理后台

访问 `admin.html` 即可使用管理后台功能：

- **添加视频** — 手动添加单个视频
- **批量导入** — 支持 JSON / CSV 格式批量导入
- **管理数据** — 搜索、删除视频
- **导出** — 导出为 JSON 或 CSV 文件

## 数据格式

`videos.json` 中每个视频的格式：

```json
{
  "name": "视频名称",
  "link": "https://www.bilibili.com/video/BV...",
  "cover": "covers/cover-1.avif",
  "uploadTime": "2026-03-28 00:00:00",
  "keywords": ["助眠", "轻语", "耳刮"]
}
```

## 部署

本项目基于 GitHub Pages，推送到 `main` 分支即可自动部署。
